CLI Network Tester

A lightweight, cross-platform command-line utility built with C# 
and .NET to measure network latency (Ping), download speeds, and
upload speeds using sustained time-based polling.

This tool allows you to choose how long you want the test to go
for, allowing faster options and more accurate options. Live UI
Spinners make sure your terminal window doesn't look dead and
frozen. There are no dependencies, no need to install .NET to run
as the program is fully self-contained.

    How to run by Operating System

       Windows

1. Open your terminal (Command Prompt or PowerShell)
2. Navigate to the folder containing the file
3. Run the executable (Paste pathname into terminal)

Example: C:\Users\User Here\Downloads\win-x64\"CLI Network Tester.exe"

        MacOS

1. Open Terminal
2. Navigate to folder (Paste pathname to FOLDER, not file)

Example: cd ~/Downloads/osx-arm64

3. Unlock executable file rights (Paste command below into Terminal)

chmod +x "CLI Network Tester"

4. Clear Apple Gatekeeper warning (Paste command below into Terminal)

xattr -d com.apple.quarantine "CLI Network Tester"

5. Launch tool (Paste FILE pathname into Terminal)

Example: ~/Downloads/osx-arm64/"CLI Network Tester"

        Linux

1. Open your system Terminal
2. Navigate to the FOLDER containing file (cd [pathname here])

Example: ~/Downloads/linux-x64

3. Apply terminal execution permissions (Paste command below into Terminal)

chmod +x "CLI Network Tester"

4. Launch tool (Paste FILE pathname into Terminal)

Example: ~/Downloads/linux-x64/"CLI Network Tester"
